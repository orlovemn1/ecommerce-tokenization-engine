# ecommerse-tokenization-engine

Проект реализует механизм автоматической трансформации транзакционных данных интернет-магазина в компактные векторные токены для последующего анализа и обучения моделей ИИ.

Технологический стек:
1. Бэкенд: Python 3.x, Django 4.2
2. API: Django REST Framework (DRF)
3. База данных: SQLite (для быстрого прототипирования)
4. Архитектура: событийно-ориентированная (Django Signals)

Как это работает
1. При сохранении заказа выполнен сигнал post_save.
2. Модуль токенизации извлекает параметры: Время (T), Площадь (A), Сумма (S), Категория (C), Пользователь (U).
3. Данные преобразуются в вектор вида [T, A, S, C, U].
4. Результат сохраняется в БД и готов к передаче в аналитические системы.

Тестовая карта

Реализовано 6 проведений проверки, включая:
* Контроль на уровне БД.
* Проверка алгоритмов динамического профилирования пользователей.
* Обработка пропусков в геоданные.
