# Система токенизации данных в электронной коммерции
Проект реализует механизм автоматической
трансформации транзакционных данных интернетмагазина в компактные векторные токены для
последующего анализа и обучения моделей ИИ.

Технологический стек:

* Бэкенд: Python 3.x, Django 4.2
* API: Django REST Framework (DRF)
* База данных: SQLite (для быстрого прототипирования)
* Архитектура: событийно-ориентированная (Django
Signals)

Как это работает:
1. При сохранении заказа выполнен сигнал
`post_save`.
2. Модуль токенизации извлекает параметры: Время (T), Площадь (A), Сумма (S), Категория (C),Пользователь (U).
3. Данные преобразуются в вектор вида `[T, A, S, C, U]`.
4. Результат сохраняется в БД и готов к передаче в аналитические системы.

Тестовая карта

Реализовано 6 проведений проверки, включая:

* Контроль на уровне БД.
* Проверка алгоритмов динамического профилирования пользователей.
* Обработка пропусков в геоданные
