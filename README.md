# Система токенизации данных в электронной коммерции
Проект реализует механизм автоматической
трансформации транзакционных данных интернет-магазина в компактные векторные токены для
последующего анализа и обучения моделей ИИ.

## Технологический стек

* **Язык программирования:** Python 3.x
* **Фреймворк:** Django 4.2
* **API:** Django REST Framework (DRF)
* **База данных:** SQLite
* **Архитектура:** событийно-ориентированная (Django Signals)

## Принцип работы

После создания нового заказа система автоматически запускает процесс токенизации с помощью сигнала **post_save**.

В процессе обработки из заказа извлекаются пять ключевых бизнес-примитивов:

* **T (Time)** — время оформления заказа;
* **A (Area)** — район доставки;
* **S (Shipping)** — тип доставки (обычная/экспресс);
* **C (Cost)** — категория стоимости заказа;
* **U (User)** — категория лояльности пользователя.

Полученные значения объединяются в единый вектор формата:

```text
[T, A, S, C, U]
```

Например:

```text
T19 A01 S1 C5 U3
```

Сформированный токен автоматически добавляется в конец файла **orders_tokens.txt** в режиме **append**, благодаря чему сохраняется полная история обработанных заказов. Такой формат удобен для последующей загрузки в системы аналитики и модели машинного обучения.

## Тестирование

Работоспособность системы подтверждена серией из шести тестовых сценариев, включающих:

* проверку корректности формирования токенов;
* верификацию алгоритма динамического профилирования пользователей;
* обработку неизвестных географических данных;
* контроль целостности данных на уровне базы данных (IntegrityError);
* проверку работы значений по умолчанию;
* проверку изоляции пользовательских данных при расчёте уровня лояльности.

Все сценарии успешно подтвердили корректность работы системы токенизации и устойчивость алгоритмов к различным вариантам входных данных.
